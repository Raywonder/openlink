Inno Setup compiler path expected by the script:

C:\Program Files (x86)\Inno Setup 6\ISCC.exe

Windows host SSH auto-start setup in elevated PowerShell:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service sshd -StartupType Automatic
New-NetFirewallRule -Name sshd -DisplayName "OpenSSH Server (sshd)" -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22

WSL SSH auto-start setup:

wsl
sudo apt-get update
sudo apt-get install -y openssh-server
sudo sed -i 's/^#Port 22/Port 2222/' /etc/ssh/sshd_config
sudo sed -i 's/^Port 22/Port 2222/' /etc/ssh/sshd_config
sudo service ssh restart
sudo update-rc.d ssh enable

Verify inside WSL:

ss -ltnp | grep 2222

Optional Windows startup helper for WSL SSH:

Create:

C:\Users\40493\start-wsl-ssh.bat

With:

wsl -u root sh -lc "service ssh start"

Then place a shortcut to that batch file in:

C:\Users\40493\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
