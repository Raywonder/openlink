What this page is for

The base OpenLink domains should be useful even before a live session starts. This landing page acts as the front door for downloads, support routing, web access, and domain status context.

Remote support and administration

Use OpenLink for full remote desktop control, support sessions, machine recovery, and managed access from your server-side controls.

  • Native Windows and macOS installers
  • Hosted session routing across approved domains
  • Support-aware workflows for staff and admins

Accessible session handling

OpenLink is positioned as a real remote-control client, not a generic link page. Accessibility and screen recording flows matter here.

  • Better fit for VoiceOver, NVDA, and support workflows
  • Web client available for quick entry
  • Native app remains the preferred control path

VoiceLink room fallback

When direct session audio is not viable, VoiceLink can create a hidden private room for that connection so the conversation can continue.

  • Admins can see an active room exists in overview
  • Entry can remain approval-gated by policy
  • Override access can stay off by default
